FLEXFUSIONX BRAND KIT
=====================
Everything used on flexfusionx.com.au: colours, fonts, logos.

OPEN FIRST: style-guide.html (double-click; works offline once unzipped)

fonts/desktop/   Install these (double-click > Install). Canva Pro: Brand Kit > Upload font.
  Inter Display Black ....... headlines (always UPPERCASE, tight letter-spacing)
  Inter Regular/Medium/SemiBold ... body text
  Archivo Expanded Bold ..... small labels and buttons (UPPERCASE, wide letter-spacing)
  (Medium/SemiBold/Black included for flexibility)
fonts/variable/  The original variable font files + licences (SIL Open Font License:
                 free for commercial use, including logos and print).
logos/           FX mark, wordmark and lockup in black, white (and red for the mark),
                 plus 1080px square avatars for Instagram/Google profile.
web/             Favicon, app icon and the social share image used on the site.
tokens.css / tokens.json   Colour and type values for developers.

Logos are PNG (transparent). If a vector (SVG/AI/PDF) original exists from the
person who designed the FX logo, keep it with this kit for print and signage.
